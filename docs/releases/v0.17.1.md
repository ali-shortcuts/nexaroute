# NexaRoute v0.17.1

Patch release on top of v0.17.0. It contains one user-facing bug fix, a release-workflow hardening, additional tests, and recorded evidence. It adds no new gateway features.

## Fixed

- **Video gateway disabled no longer shows a global error (issue #246).** The admin snapshot now reports `video.enabled`; the dashboard shows a neutral "Video gateway is not enabled" state inside Video Studio only, does not poll the video API when it is disabled, and never raises a "Video API HTTP 404" banner on Overview, Providers, Routing, Activity or Settings. Covered by the browser E2E (`scripts/test-browser-e2e.py`) with screenshots under `docs/browser-evidence/video-disabled/`.
- **Dashboard regressions (M2-1).** Page title/content offsets, the Video Studio empty-state call-to-action gap and privacy-badge colors in dark and light themes were verified in a real browser and corrected in `styles.css`; evidence under `docs/browser-evidence/m2-1/`.

## Hardened

- **Release workflow.** The `publish` job now requires a `push` event on a `v*` tag, so a manual `workflow_dispatch` can never publish. A dispatch dry-run additionally downloads the uploaded artifact and verifies every file and `SHA256SUMS` round-trip.

## Tests and evidence

- New default-configuration concurrency integration test: more than 32 upstream requests in flight with the default provider limit (race detector enabled).
- Recorded evidence: current aggregate coverage measurement, competitor capability matrix audit (17 rows, 55 verified / 30 unverified cells), repaired gateway benchmark harness with published measurements, hotspot decision (no actionable hotspot found), remote branch containment audit, and dependency-policy alignment with `govulncheck`.
- `docs/reports/COMPLETION_CHECKLIST.md` is the roadmap of work that is **not** done.

## Honest boundaries

Unchanged from v0.17.0, and still **NOT VERIFIED** in this environment: live OIDC, Redis/Postgres interoperability, OS keyring/KMS, a real commercial video provider, Docker image build, and human visual acceptance with a configured real provider. The roadmap items M2-2 onward in the completion checklist (Access, Budgets, Policies, Observability, Audit page, Evals, Playground, i18n, Helm, extra provider adapters, MCP gateway, and so on) are not implemented in this release.
