# NexaRoute v0.21.0

Security-hardening release on top of v0.20.2. Closes SSRF gaps in egress validation, routes token counting through virtual privacy policies, and fixes two routing/translation bugs found in a full codebase audit.

## Security

- **SSRF hardening** (`internal/egress`): the special-purpose IP blocklist is now complete — CGNAT `100.64.0.0/10`, TEST-NETs, benchmarking, reserved, Teredo, site-local, `::/96`, and NAT64/6to4 forms of blocked IPv4 addresses are rejected. Previously only `IsLoopback`/`IsPrivate` were checked, so SSRF could reach Tailscale peers and other internal ranges.
- **Loopback tautology closed**: `AllowLoopback` was derived from the target URL's own scheme, so `http://<any host>` was accepted and API keys could be sent in cleartext. Loopback is now determined from the resolved host, and plain `http` is only allowed for explicitly loopback hosts.
- **Privacy**: `count_tokens` now resolves virtual endpoints and applies the Anthropic protocol restriction before selecting an upstream, instead of silently falling back to a local estimate for virtual public models. A `no_training` request can never reach a training-enabled provider.

## Fixed

- **Router**: session-affinity pin no longer crosses priority tiers in `orderReadyMesh` — a stale pin on a low-priority deployment could previously jump ahead of healthy higher-priority deployments. Now consistent with `orderCostAware`.
- **Translation**: legacy OpenAI→Anthropic path mapped `stop_sequence` to `max_tokens`; now correctly maps to `stop_sequence`.

## Breaking

- Providers with `http://<non-loopback host>` base URLs are now rejected at config validation. Use `https://`, or `http://` only with loopback hosts (`localhost`, `127.0.0.1`, `::1`).

## Verification

- New `ssrf_matrix_test.go`: 27 of 61 matrix cases fail on the old code; all pass on the new code.
- Privacy regression tests cover OpenAI Chat, Anthropic Messages, OpenAI Responses, and native `count_tokens` ingress.
- `./scripts/verify.sh` — full unit, vet, race, fuzz, and browser acceptance suite.
