# NexaRoute v0.17.0-rc.1

## Integrated release candidate

This candidate packages the existing LLM gateway and the optional Video Gateway in one tested release pipeline.

### Included

- OpenAI-compatible Chat Completions and Responses routes
- Anthropic-compatible Messages and token-count fallback
- provider registry, health probing, routing, fallback, compatibility learning and client authentication
- control-plane dashboard with responsive Overview, Providers, Routing, Activity, Settings and Video Studio pages
- optional `/v1/video/` runtime with bounded workers, durable single-process JSON job store, idempotency, cancellation, budget hooks, webhook verification and local asset safety primitives
- `nexaroute-videogen` Linux amd64/arm64 development utility
- Linux amd64/arm64 gateway binaries, installer, checksums, Video config example and Video Gateway documentation

### Pipeline evidence

The release pipeline runs, in order:

1. `gofmt`, unit/integration tests, `go vet`, race tests and short fuzz checks;
2. browser control-plane and Live Visual Agent acceptance;
3. bounded stress and local runtime smoke checks;
4. reproducible gateway and videogen builds for amd64/arm64;
5. checksum verification for every artifact;
6. release smoke with Video enabled, fake provider discovery, embedded UI and asynchronous job admission;
7. installer lifecycle tests and embedded-version checks.

### Honest boundaries

This is a release candidate, not a claim that a real commercial video provider is bundled. The fake provider is development-only. Multi-node Video job storage, a production video provider adapter, full asset/event admin APIs, and episode/audio/subtitle composition remain follow-up work. The installer installs the canonical `nexaroute` gateway; `nexaroute-videogen` is distributed as a separate developer artifact.
