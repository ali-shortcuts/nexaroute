# NexaRoute v0.20.2

Patch release on top of v0.20.1. It contains the same unified runtime as v0.20.0 (Gateway and Video CLI Piper narration, Video Studio subtitles and checkpoints, runtime hardening) and fixes the release verification path.

## Fixed

- The installer upgrade lifecycle test wrote `SHA256SUMS` with the `uname` architecture (`x86_64`) instead of the release asset architecture (`amd64`/`arm64`). This made the `Installer lifecycle tests` step fail in the Release workflow for v0.19.0, v0.20.0 and v0.20.1, so the `publish` job never passed verification. The test now keeps the two names separate; the Release verify path (build, release smoke, installer lifecycle) was reproduced on GitHub Actions and passes.

## Notes

- v0.19.0, v0.20.0 and v0.20.1 GitHub Releases were not produced by a passing Release workflow. v0.20.2 is the first release of this line whose verify job passes before publish.
