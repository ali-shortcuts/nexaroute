# NexaRoute v0.18.0

Minor release on top of v0.17.0. It rolls up the Video Gateway work and fixes merged to `main` since v0.17.0, hardens the release workflow, and adds tests and recorded evidence. Items are listed by the pull request that introduced them.

## Video Gateway

- `nexaroute-videogen` CLI connected to the durable Video Gateway API (#266).
- FFmpeg atomic composition preserves the output format (#267).
- Optional local ComfyUI generation provider (#268).
- Local episode assembly with audio and subtitles (#269).
- Local compose CLI; unsupported provider inputs are rejected (#270).
- Multi-shot checkpoints are persisted and final episodes composed (#271).
- Video Studio asset downloads and the multi-shot workflow (#272).

See `docs/VIDEO_GATEWAY.md` for configuration. The optional Video Gateway stays disabled by default.

## Fixed

- A disabled video gateway no longer raises a global "Video API HTTP 404" banner; the state is shown inside Video Studio only (issue #246, #248).
- Dashboard regressions in page offsets, the Video Studio empty-state call-to-action and privacy-badge colors in dark and light themes were verified in a real browser and corrected (#263).

## Hardened

- The release `publish` job requires a `push` event on a `v*` tag, so a manual `workflow_dispatch` cannot publish. A dispatch dry-run also downloads the uploaded artifact and verifies every file and `SHA256SUMS` round-trip (#260).

## Tests and evidence

- Default-configuration concurrency integration test with more than 32 upstream requests in flight (#259).
- Recorded evidence: aggregate coverage measurement (#255), competitor capability matrix audit (#256), repaired benchmark harness with published measurements (#257), hotspot decision (#258), remote branch containment audit (#261), dependency policy and `govulncheck` alignment (#262), README OIDC status sync (#265).
- `docs/reports/COMPLETION_CHECKLIST.md` (#254) is the roadmap of work that is **not** done.

## Honest boundaries

Still **NOT VERIFIED** in this environment: live OIDC, Redis/Postgres interoperability, OS keyring/KMS, a real commercial video provider, the ComfyUI provider against a live ComfyUI server, a Docker image build, and human visual acceptance with a configured real provider. Roadmap items from M2-2 onward in the completion checklist are not implemented.
