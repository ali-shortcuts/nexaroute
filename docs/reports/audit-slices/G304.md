## Patches

- `internal/video/storage/local_filesystem.go`: `Local.Put` now rejects `.`/`..` path components, creates each asset directory without following a symlink, and verifies the resolved directory remains below the resolved storage root.
- `cmd/gateway/provider_accept.go`: `writeProviderAcceptReport` now writes through a private temporary file and `Rename`, avoiding symlink-following `O_TRUNC` and partial reports.

## Residual risk

- Paths explicitly selected by an operator (config, backup, restore, audit, TLS, secret-store, and provider inputs) remain trusted. Protecting those files from a malicious local user requires filesystem permissions and is outside request-level path sanitization.
- `appendPolicyAudit` appends to an operator-selected audit path. It is not part of this slice's confirmed HTTP path bug, but an audit path in an untrusted directory would still be subject to local symlink/permission attacks; operators should keep the audit directory private.
- The storage fix prevents traversal and symlink escape below the local root. It does not protect against a malicious process with write access to the storage root racing directory replacement after validation; that requires OS-level isolation.
