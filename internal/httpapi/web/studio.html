Connect

Enter the gateway admin key. It stays in this tab's session storage and is sent only to this gateway as x-admin-key. The studio never asks for, stores, or sends provider secrets; node credentials are references only.

How this studio works

  1. Pick a template from the gallery, or start from an empty draft with a trigger node.
  2. Add nodes from the palette. Drag them on the canvas, or select one and move it with the arrow keys.
  3. Connect nodes: select a node, then use its Connect from here control and pick the target node. Branch nodes ask which branch the edge takes.
  4. Configure the selected node in the inspector. Fields come from the node's registry schema; input values may be literals or $.path references into the run input and earlier node outputs.
  5. Validate, then Save as a draft. Publish creates an immutable revision; inspecting a revision is read-only.
  6. Runs are started from a published revision. The timeline shows per-node status, attempts, duration, safe outputs, and error codes only — never raw prompts, secrets, or raw error text.
