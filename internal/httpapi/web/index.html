Access keys

Virtual client keys for the data plane (/v1/*). Clients send them as Authorization: Bearer … or x-api-key.

…
NameKeyEnabledRequests

Turning the requirement on with zero enabled keys is rejected by design — generate a key first. The admin API and Web UI are unaffected.

CLI Tools

Point coding agents at NexaRoute; Ready Mesh handles the upstream pool.

Claude Code / Anthropic

Use the local Messages endpoint.

ANTHROPIC_BASE_URL=http://127.0.0.1:8080
ANTHROPIC_API_KEY=local-placeholder
The placeholder key is only for clients that require a non-empty value.

OpenAI-compatible tools

Use Chat Completions through the same routing plane.

OPENAI_BASE_URL=http://127.0.0.1:8080/v1
OPENAI_API_KEY=local-placeholder
Aliases such as auto/coding can map multiple deployments behind one client model.
