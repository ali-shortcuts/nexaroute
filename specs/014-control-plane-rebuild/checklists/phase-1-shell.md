# Phase 1 Shell Checklist

- [ ] Five-item primary navigation only.
- [ ] One application shell and one CSS token system.
- [ ] Central API/auth client.
- [ ] Central SSE client with bounded retry and teardown.
- [ ] No inline `onclick` handlers.
- [ ] No native prompt/confirm/alert.
- [ ] No fake state or synthetic telemetry.
- [ ] Visible focus and keyboard page/dialog navigation.
- [ ] Reduced-motion support.
- [ ] Narrow-layout transformation without horizontal overflow.
- [ ] Static assets remain embedded in the Go binary.
